# Troubleshooting

Diagnosing publish and rendering problems for `foo.zone`.

## What `--publish` does

`./gemtexter --publish` already runs generate, git add, and git sync. You do
not need to generate or commit separately. If publish succeeded but the site
is old, inspect the live page with `curl` (see
[Verification](verification.md)) before assuming publish failed.

## Stale site after a successful publish

1. Verify with `curl -fsSL https://foo.zone/...` (not a browser) — see
   [Verification](verification.md).
2. Compare the live page against the local generated file in
   `~/git/foo.zone-content/html/...`.
3. Inspect `/tmp/gemtexter-publish.log` for push failures.

## Output branches look wrong

- Inspect `~/git/gemtexter/gemtexter.conf` and `lib/git.source.sh` for the
  branch/sync configuration.
- Inspect `lib/generate.source.sh` for what gets generated.

## Feed issues

- Inspect `lib/atomfeed.source.sh` and `lib/gemfeed.source.sh`.

## HTML theme issues

- Inspect `~/git/gemtexter/extras/html/themes/`.

## Notes index issues

- `gemtext/notes/index.gmi` is auto-generated by `lib/notes.source.sh` from the
  `*.gmi` files in `gemtext/notes/` (title taken from each note's first `#`
  heading, sorted reverse). Do not hand-edit it. If it's missing or stale, run
  `./gemtexter --generate`.
